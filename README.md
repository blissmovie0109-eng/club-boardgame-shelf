# 동아리 아지트 보드게임 목록

동아리 회원들이 로그인 없이 아지트 보유 보드게임을 확인하고, 관리자는 BoardLife 게임 상세 페이지를 복사해 붙여넣거나 직접 입력해 목록을 관리하는 Flask 웹사이트입니다.

## 주요 기능
- 공개 게임 목록 / 검색
- 인원수·보유 장소 필터
- 웨이트 / 이름순 정렬
- 관리자 비밀번호 로그인
- BoardLife 게임 상세 페이지 복사·붙여넣기 가져오기
- 보유 장소 관리
- 영상 / 룰북·자료 링크
- 직접 추가 / 수정 / 삭제
- 로컬 SQLite, 배포 시 PostgreSQL(Neon/Supabase) 지원

## BoardLife 가져오기
BoardLife는 Render 서버의 직접 요청을 403으로 차단할 수 있으므로 URL 서버 자동 가져오기는 사용하지 않습니다.

관리자 화면에서 BoardLife 게임 상세 페이지를 연 뒤 `Ctrl+A` → `Ctrl+C`로 페이지 전체를 복사하고, 가져오기 상자에 `Ctrl+V`로 붙여넣습니다. 자동으로 채워진 내용을 확인·수정한 뒤 저장합니다.

## Render 배포
저장소 루트의 `render.yaml`을 이용해 배포할 수 있습니다.

필수 환경변수:
- `ADMIN_PASSWORD`: 관리자 비밀번호
- `DATABASE_URL`: PostgreSQL 연결 문자열

`SECRET_KEY`는 Render 설정에서 자동 생성되도록 구성되어 있습니다.

배포 후 `/health`에서 `{"ok": true}`가 반환되는지 확인하세요.
