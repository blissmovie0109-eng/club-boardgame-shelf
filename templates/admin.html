⚡ 여러 게임 한 번에 기본 등록

BoardLife에서 게임이 여러 개 보이는 목록·순위 페이지를 통째로 복사하면 게임 링크와 이름을 찾아 한 번에 등록합니다.

  1. BoardLife에서 등록할 게임들이 여러 개 보이는 페이지를 엽니다.
  2. Ctrl+A → Ctrl+C 후 아래 상자에 Ctrl+V합니다.
  3. 찾아낸 게임 목록에서 필요 없는 항목만 체크 해제하고, 확장이라면 종류를 바꿉니다.
  4. 선택한 게임 한 번에 등록을 누릅니다. 이미 등록된 게임 번호는 자동으로 건너뜁니다.
