📋 BoardLife 페이지 복사로 게임 추가

BoardLife의 서버 자동 접근 차단과 관계없이, 브라우저에 보이는 게임 정보를 복사해서 등록합니다.

+ 직접 추가
  1. BoardLife에서 등록할 게임의 상세 페이지를 엽니다.
  2. Ctrl+A → Ctrl+C로 페이지 전체를 복사합니다. (Mac: ⌘A → ⌘C)
  3. 아래 큰 상자를 클릭하고 Ctrl+V로 붙여넣습니다.
  4. 자동으로 채워진 정보를 확인하고, 본판 / 확장 / 독립형 확장을 선택합니다.
  5. BoardLife 게임 번호가 이미 등록돼 있으면 중복 등록을 자동으로 막습니다.
  6. 확인한 게임 추가를 누릅니다.

📦 CSV로 여러 게임 한 번에 등록

엑셀이나 구글시트에 게임을 정리한 뒤 CSV로 올리면 최대 5,000행을 한 번에 처리합니다.

⬇ CSV 양식 받기
필수: 게임명 추천: BoardLife주소 — 게임 번호로 중복을 정확하게 거릅니다. 게임종류: 본판 / 확장 / 독립형 확장 본판게임명: 확장이라면 어떤 본판에 붙는지 적어두면 관리하기 쉽습니다.

UTF-8 또는 Excel 한글 CSV(CP949)를 지원합니다. 중복은 자동으로 건너뛰고 완료 후 처리 결과를 알려줍니다.
